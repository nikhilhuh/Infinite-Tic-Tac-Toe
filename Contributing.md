# Contributing Guidelines

Thank you for considering contributing to **Infinite Tic Tac Toe**! 🚀  
We welcome all kinds of contributions — bug fixes, new features, performance improvements, documentation updates, and more.  

---

## 🛠 How to Contribute

1. **Fork** the repository  
2. **Clone your fork** to your local machine  
3. **Create a new branch** for your changes (e.g., `feature-ai-hard-mode`)  
4. **Make your changes** in the codebase  
5. **Commit your changes** with a clear and descriptive message  
6. **Push to your branch** on your fork  
7. **Open a Pull Request (PR)** to the `main` branch of this repository  

---

## ✅ Contribution Rules

- Keep PRs focused on **a single feature or fix**  
- Write clear commit messages (example: `fix: corrected timer reset bug`)  
- Follow the project’s coding style (use Prettier/ESLint if set up)  
- Update or add documentation if your change affects usage  
- Ensure that all changes are tested and do not break existing functionality  

---

## 🧩 Types of Contributions

- **Bug Fixes** — squash those errors!  
- **Features** — add new gameplay modes, UI improvements, or optimizations  
- **Documentation** — improve clarity in README, add tutorials, or fix typos  
- **Testing** — write tests or report reproducible bugs  

---

## 🐛 Reporting Issues

If you find a bug or unexpected behavior:  
- Search the [Issues](../../issues) tab to see if it’s already reported  
- If not, open a new issue with:  
  - A clear title  
  - Steps to reproduce  
  - Expected vs actual behavior  
  - Screenshots/logs if relevant  

---

## 💡 Feature Suggestions

Have an idea to make the game better?  
- Open an **Issue** with the `enhancement` label  
- Describe the feature, why it’s useful, and possible implementation details  

---

## 🧑‍💻 Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/).  
By contributing, you agree to maintain a respectful, collaborative, and inclusive environment.  

---

## 🙌 Getting Started

If this is your first time contributing:  
- Start with **good first issue** or **help wanted** labels in the Issues tab  
- Check the README for setup instructions  
- Join discussions to learn more about ongoing work  

---

## 🎉 Final Note

Every contribution counts — big or small.  
Whether it’s fixing a typo, improving performance, or adding a whole new game mode, we appreciate your help! 💙
