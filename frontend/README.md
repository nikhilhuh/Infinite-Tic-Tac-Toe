# 🎨 Infinite Tic Tac Toe — Frontend

This is the **frontend** for the Infinite Tic Tac Toe game, built with **React + TypeScript**.  
It provides a smooth UI, local play, AI opponents, and online multiplayer support. 

---

## ✨ Features

- 🖥 **Local Play** — Play with a friend on the same device  
- 🤖 **AI Opponent** — Choose from **Easy, Medium, Hard** difficulty levels  
- 🌍 **Online Multiplayer** — Play with friends via the internet using Socket.IO  
- ⚡ **Time-Limited Moves** — Marks disappear after 20 seconds  
- 🎯 **5-in-a-Row to Win** — Strategy extended beyond the classic 3x3 grid  
- 🎨 Modern animations with **Framer Motion** and clean UI 

---

## 🛠 Tech Stack

- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Socket.IO Client](https://socket.io/)
- [Axios](https://axios-http.com/)
- [Framer Motion](https://www.framer.com/motion/) for animations
- [Lucide React](https://lucide.dev/) for icons
- [React Router v6](https://reactrouter.com/) for navigation
- [React Spinners](https://www.davidhu.io/react-spinners/) for loading states
- [UUID](https://www.npmjs.com/package/uuid) for unique identifiers

---

## 📦 Setup

### Install Dependencies

```bash
cd frontend
npm install
```

### Environment Variables

```bash
VITE_BACKEND_URL=http://localhost:3001
```

---

## 🚀 Running the frontend

```bash
cd frontend
npm run dev
```

The frontend will run at: http://localhost:3000
