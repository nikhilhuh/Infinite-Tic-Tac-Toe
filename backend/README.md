# ⚡ Infinite Tic Tac Toe — Backend

This is the **backend** for the Infinite Tic Tac Toe game, built with **Express + Socket.IO**.  
It powers the online multiplayer mode and handles real-time communication between players.

---

## ✨ Features

- 🌍 **Online Multiplayer** — Real-time gameplay with friends  
- ⚡ **Socket.IO Integration** — Fast and reliable WebSocket communication  
- 🔒 **CORS & Environment Variables** support  
- 🛠 Lightweight Express API  

---

## 🛠 Tech Stack

- [Express](https://expressjs.com/)  
- [Socket.IO](https://socket.io/)  
- [CORS](https://www.npmjs.com/package/cors)  
- [dotenv](https://www.npmjs.com/package/dotenv)  

---

## 📦 Setup

### Install Dependencies

```bash
cd backend
npm install
```

### Environment Variables

```bash
PORT=3001
FRONTEND_URL=http://localhost:3000
PING_MESSAGE=pong
```

---

## 🚀 Running the frontend

```bash
cd backend
npm run dev
```

The backend will run at: http://localhost:3001
